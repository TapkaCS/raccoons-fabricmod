# 🦝 Raccoons!

A Fabric mod that adds mischievous raccoons to Minecraft. Tame them, give them a straw hat, and keep an eye on your food chests!

## Features

- Tame raccoons with apples and breed your companions.
- Switch between following, wandering, and sitting.
- Craft straw hats and dye their bands.
- Watch raccoons steal food from chests and wash it before eating.
- Feed them to unlock the chunky variant.
- Use a raccoon bell to call your nearby tamed companions.
- Complete raccoon-themed advancements.

## Requirements

Version **1.3.0** requires:

- Minecraft **26.3**
- Java **25**
- Fabric Loader **0.19.5 or newer**
- Fabric API **0.161.0+26.3**
- GeckoLib **5.5.7 for Fabric 26.3**

Install the mod and its dependencies in your instance's `mods` folder.

## Development status

This is a hobby project, and I am not a professional mod developer. AI tools have helped with parts of the code and troubleshooting.

Version 1.3.0 has received basic testing, but not every feature or mod combination has been thoroughly tested. Bugs and rough edges may remain.

## Building

Use Java 25.

Linux and macOS:

```sh
./gradlew build
```

Windows:

```bat
gradlew.bat build
```

The compiled mod is generated in `build/libs/`.

## Bug reports and contributions

Bug reports, testing, fixes, and feature suggestions are welcome.

When reporting a bug, include:

- Minecraft, mod, and dependency versions.
- Steps to reproduce the problem.
- Expected and actual behavior.
- Relevant logs or a crash report.

Please open an issue before starting a large change. I work on the mod in my spare time, so replies and updates may take time.
